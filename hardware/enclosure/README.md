# Hardware / Enclosure
🚧 Work in Progress: This repository is currently under active development. Files and documentation are being added incrementally.

This directory contains the design files need to order parts for the sensor enclosure and component tray.

### 1. Component tray versions (*.stl)

* v1 - original design used by the research project
* v2 - next generation tray to resolve fragility of the SEN-55 guides

### 2. Acrylic enclosure (*.dxf)

All 6 *.dxf original files for the enclosure used by the research project.

* "front" -- refers to the side with the cutouts for power, most often in the back of the images we've provided
* "back" -- refers to the side dominate by horizontal vents and connection tabs along the full top edge, most often in the front of the images we've provided
* "sen55" -- the side with the design guide compliant openings for the SEN55 input and output ports
* "ani-sen55" -- the side opposite the SEN55
* "bot" -- the bottom
* "top" -- the top L-shaped panel with the cut-out for the touchscreen display
  
Caution: we may swap the front/back naming to align with drawings and photographs
